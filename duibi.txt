你是一位资深 Rust 桌面应用开发专家,擅长高性能、隐私优先的本地工具开发。请从零开始为我完整设计和实现一个现代化的桌面文本对比与合并工具,要求体验明显超越 https://diffsuite.com/text-compare-plus/。

### 核心目标
- 纯本地桌面应用(Windows / 无macOS / 无Linux)
- 所有文本处理、对比、合并全部在本地完成,绝不上传任何用户数据
- 实时对比、流畅编辑、强大合并能力
- 界面现代、专业、高效,适合开发者、写作者、编辑使用

### 必须实现的核心功能(对标并超越原站)
1. 双栏并排文本编辑器(左侧 / 右侧)
   - 行号显示
   - 差异实时高亮(删除红、新增绿、修改黄或更清晰的颜色方案)
   - 中间差异导航与合并箭头(支持单向和双向快速合并)
   - 同步滚动(可选开关)
   - 虚拟滚动,支持超大文本(几十万行)不卡顿

2. 实时 Diff
   - 输入即对比,无需手动点击按钮
   - 支持行级、词级、字符级差异高亮(可切换)
   - 智能对齐(不是简单逐行对比)
   - 可选忽略空白、大小写、空行等选项

3. 编辑与操作
   - 打开本地文件(支持多编码自动检测)
   - 撤销 / 重做(独立左右两侧)
   - 复制、全选、清空
   - 交换左右文本
   - 查找 / 替换(支持正则、高亮所有匹配)
   - Word Wrap 开关
   - 清理工具:
     - 移除重复行
     - 去除行首/行尾空白
     - 删除空行
     - 将换行替换为空格
     - 排序行、去重排序等

4. 合并能力
   - 点击箭头将单侧差异合并到另一侧
   - 支持批量接受所有左侧 / 右侧变更
   - 三路合并预留扩展能力(未来可加)

5. 其他增强(超越原站的关键点)
   - 深色 / 浅色主题 + 跟随系统
   - 语法高亮(至少支持常见语言:Rust、Python、JS、JSON、Markdown、YAML 等)
   - 差异统计(新增/删除/修改行数、相似度百分比)
   - 导出:复制结果、导出 unified diff、导出左右最终文本
   - 最近打开文件历史
   - 可调节字体大小、行高
   - 快捷键完整支持(Ctrl+F、Ctrl+H、Ctrl+D、Ctrl+Z、Ctrl+Shift+Z、Ctrl+S 保存结果等)
   - 窗口布局可调整(左右比例拖动)
   - 性能指示(大文件处理时显示进度)

### 技术栈强制要求(Rust 生态)
优先推荐方案(请按此实现,除非有更好理由):
- 框架:**Dioxus**(优先)或 **Tauri 2 + Leptos / Dioxus**
  - 原因:跨平台桌面支持优秀,性能高,开发体验好
- Diff 核心库:`similar`(必须使用,支持 Myers / Patience 等算法)
- 文本缓冲区:`ropey`(高效处理超大文本)
- 文件对话框:`rfd`
- 语法高亮:`syntect` 或 `tree-sitter`
- 状态管理与响应式:框架自带的 Signals / Hooks
- 构建与打包:支持一键生成 Windows exe、macOS dmg、Linux AppImage

备选纯原生方案(如果认为更合适):`egui` + `eframe`(极致性能与体积)
